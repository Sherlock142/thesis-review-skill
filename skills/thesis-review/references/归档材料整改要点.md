# 归档材料整改要点

> 归档材料指论文正文以外的表格：任务书、开题报告、指导情况记录表、
> 指导教师评阅表、交叉评阅表、答辩记录与成绩评定表等。
> 这些材料通常是固定模板填空，整改目标是「对照模板补齐/改正，不破坏版式」。

---

## 核心方法：lxml 直改 word/document.xml

**绝对禁止用 python-docx 的段落索引做 XML 定位**——实测偏差最大 440 段。
一律用**文本搜索定位**：先按文本内容找到目标段落/单元格，再改其 XML。

### 基本流程

```python
import zipfile
from lxml import etree

W = '{http://schemas.openxmlformats.org/wordprocessingml/2006/main}'

# 1. 解包 docx
with zipfile.ZipFile(src) as z:
    xml = z.read('word/document.xml')
root = etree.fromstring(xml)

# 2. 文本搜索定位
for p in root.iter(f'{W}p'):
    text = ''.join(t.text or '' for t in p.iter(f'{W}t'))
    if '目标文本' in text:
        # 改这里
        ...

# 3. 重新打包（其余文件原样保留）
```

### 复选框（PUA 码）

归档表里的勾选框是私用区字符（PUA），不是普通字符：
- 空心框 `□` = U+2610
- 实心框 `☑` = U+2611
- 部分模板用 `Wingdings` 字体的 PUA 码（如 U+F0A8 / U+F0A9）

改勾选状态时**必须保留原字体**，否则符号会变成乱码。最稳妥：直接替换成模板里已勾选单元格的整段 XML。

### 表格单元格定位

合并单元格会让 `row.cells[i]` 索引失真。用 grid→tc 归属法判断真实结构：

```python
prev = None; groups = []
for ci, c in enumerate(row.cells):
    if prev is not None and c._tc is prev:
        groups[-1][1] = ci
    else:
        groups.append([ci, ci, c])
    prev = c._tc
```

- 合并区**只在首行写**，续行跳过（对续行写空串会连带抹掉首行内容）。
- 「标签+值」成对的行必须**整行重写**，不要盲清后半段——会把标签一起删掉。

## 通用检查清单

| 项 | 要点 |
|---|---|
| 目录一致性 | 目录条目与正文标题文字、页码一致 |
| 日期 | 各表日期逻辑自洽（开题 < 中期 < 答辩） |
| 姓名学号 | 全套材料同一学号、姓名，无错别字 |
| 题目 | 全套材料题目与论文封面完全一致 |
| 签名栏 | 该留空的留空，该签的已签 |
| 文献真实性 | 参考文献需 WebSearch 核验，勿留虚构条目 |

# 高频问题实证库

> 本库记录本科毕业论文审查中最常出现、最容易被答辩组点名的问题。
> 来源于真实审查经验，用于指导「该查什么」。分内容结构与版式两类。
> ⚠️ 版式类（字体/字号/行距/缩进）必须用 wps-agent 读取生效值才能确认，勿凭 python-docx 的 `?`/`inherit` 判断。

---

## 一、内容结构类（高频）

### 1. 章节结构
- 缺「总结与展望」/「结论」章节——本科论文必备，答辩常点名。
- 章节编号格式不统一：半角/全角点号混用、编号与标题之间缺空格。
- 续表标题多余中点号、表编号重复。

### 2. 图件缺失（最致命）
- 缺用例图、系统架构图、E-R 图、系统功能模块图。
- 实现章节只有代码堆砌，**零界面截图**——答辩高频扣分项。
- 图题与正文描述不符（如标题写「砍价管理」正文讲「秒杀活动」）。
- 多张图标注同一编号（图4-1 冲突）。

### 3. 需求与实现脱节
- 实现章节出现的功能，需求分析里没描述（如秒杀/砍价功能凭空出现）。
- 反之，需求里承诺的功能实现章节找不到。

### 4. 表格
- 表说明文字穿插在表头和表数据之间，排版混乱。
- 表标题与内容不符（标题「用户信息表」内容是订单主表）。
- 表头拆行。

### 5. 数据库 / 1NF
- E-R 图与表结构不一致（文本描述有权限约束，图未体现）。
- 用 `images` 字段存多张图片，违反第一范式——应独立拆图片表。
- 缺关键字段（如收货地址）。

### 6. 测试数据可信度
- 声称 N 条测试数据，正文仅展示十余条——建议附录补全清单。
- 测试用例缺关键功能场景。

### 7. 参考文献
- 数量偏少（本科建议 ≥15 条）。
- 混合条目格式、`[C]` 会议论文占比异常、疑似虚构或非学术来源。
- 与正文主题关联度低。

### 8. 技术一致性
- 同一系统技术栈前后矛盾（如 Vue2+ElementUI / Vue3+NaiveUI / Vue3+ElementPlus 三重矛盾）。
- 安全方案矛盾（JWT vs SaToken）。

### 9. 英文摘要
- 含中文标点 / 全角字符。
- 长度异常（过短或过长）。

### 10. 错别字
- 「登陆」应为「登录」（全文多处）。
- 口语化表达、措辞不当（「拟引入」「拟采用」）。

## 二、版式类（必须用 wps-agent 读生效值）

| 检查项 | 常见错误 |
|---|---|
| 中文字体 | 摘要/正文未用模板指定字体（如要求宋体实际是 Calibri） |
| 字号 | 正文非小四、标题字号错误 |
| 行距 | 模板要求固定值 20pt，实际单倍或多倍 |
| 首行缩进 | 应为 2 字符，实际 0 或过大 |
| 对齐 | 正文应两端对齐，实际左对齐或居中 |
| 段前段后 | 与模板不符 |
| 页边距 | 上下左右与模板不符 |

> 判定方法：`format.get_paragraph_format` + `get_run_font` 读论文与模板同位置段落，
> 逐字段对比，差异即为问题。详见 `wps-agent工具速查.md`。

## 三、答辩意见核查三态

审查答辩后论文时，逐条对照意见与论文实际内容：

- ✅ **已修正** → 仅记录，不产生审查条目
- ❌ **未修正** → 纳入审查条目
- ⚠️ **部分修正** → 纳入审查条目，指出已改部分和遗漏部分

> 去重合并：已修正的答辩意见不再重复出现在审查问题列表里。

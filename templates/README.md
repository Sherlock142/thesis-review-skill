# 放置你的论文格式模板

把你学校/学院的**论文格式模板 .docx** 放到这个目录，例如：

```
templates/
└── 我的学校论文模板.docx
```

Agent 做精确版式核验（字体、字号、行距、缩进、页边距）时，会读取这里的模板，
与待审论文的同位置段落逐字段对比。

## 说明

- 支持多个模板（不同专业/届别），审查时告诉 Agent 用哪个即可。
- 模板文件不会上传到仓库（已在 `.gitignore` 忽略），只留在你本地。
- 没有模板也能用：Agent 会退化为只查内容结构问题，并在报告里注明。
- 模板最好是你学校官方发布的 Word 版（.docx），不是 PDF。
